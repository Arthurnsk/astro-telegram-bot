# Astro Telegram Bot

Bot that publishes a daily esoteric forecast to a Telegram channel and answers users
on demand.

## What a post contains

- Tarot card, rune and number of the day.
- Current moon phase (Farmsense API).
- A short forecast written by an LLM (Groq) from these ingredients.
- An illustration generated by Pollinations AI, with a stock-photo fallback.

Posts go out every day at `POST_TIME` (APScheduler); users can also press
"🔮 Получить прогноз" to get a forecast in the chat.

## Stack

Python · pyTelegramBotAPI · APScheduler · Groq API · requests

## Run

```bash
cp .env.example .env     # bot token, channel, Groq key
pip install -r requirements.txt
python main.py
```

The bot must be an administrator of the channel to post there.

## Кратко

Бот для Telegram-канала: каждый день публикует прогноз (таро, руна, число дня, фаза
луны, текст от ИИ и картинка), а по кнопке присылает прогноз пользователю.
